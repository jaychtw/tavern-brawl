# Tavern Brawl
Once upon a time in the Wild West.

Open index.html locally or serve this directory with python3 -m http.server. No installation or build required.

Move with ← / → or A / D, fire with Space, pause with P / Escape. Touch buttons provide the same controls. Break 20 items, dodge marked throws, and land three countershots when the outlaw is open. Settings and your best completed score are saved on this device when storage is available.
